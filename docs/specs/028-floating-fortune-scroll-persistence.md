# 028 · 오늘의 운세 플로팅 캐릭터 스크롤 고정

## 목적

사주 해석 결과가 길어 페이지를 스크롤해도 오늘의 운세 한복 캐릭터가 화면 우측 상단에 계속 떠 있도록 합니다.

## 동작

1. 사주 해석 성공 전에는 플로팅 캐릭터를 표시하지 않습니다.
2. 해석 성공 후에는 캐릭터를 반투명 입력 카드 바깥에 렌더링합니다.
3. 사용자가 페이지를 위아래로 스크롤해도 캐릭터의 뷰포트 기준 상단·우측 위치가 유지됩니다.
4. 캐릭터의 둥실거림, 모바일 안전 영역, 키보드 포커스와 오늘의 운세 이동 동작은 유지합니다.
5. 결과를 닫거나 삭제하면 캐릭터도 숨깁니다.

## 확인 기준

- 플로팅 링크가 `backdrop-filter`가 적용된 `.input-card`의 하위 요소가 아닙니다.
- 스크롤 전후 링크의 화면 기준 상단·우측 위치가 유지됩니다.
- Spec 026·027의 결과 후 표시와 생년월일 일회 전달 동작을 유지합니다.
- 관련 자동 시험, 전체 검사와 프로덕션 빌드가 통과합니다.

## 검증 기록

- 원인: `position: fixed` 링크가 `backdrop-filter`를 사용하는 `.input-card` 안에 있어 카드가 고정 위치의 포함 블록이 되었고, 카드와 함께 스크롤되었습니다.
- 수정: 결과 이후 표시 조건과 생년월일 전달 동작은 유지하면서 `FloatingFortuneLink`를 `.input-card`의 형제 요소로 이동했습니다.
- 회귀 시험: 독립 서브에이전트가 플로팅 링크의 카드 외부 렌더링, 표시 조건, 생년월일 전달·초기화와 기존 고정 위치 CSS를 검사하도록 보강했으며 관련 시험 9개가 모두 통과했습니다.
- 전체 검증: `npm run check`에서 TypeScript 검사와 전체 시험 127개가 통과했고, `npm run build`도 통과했습니다.
- 화면 검증: 브라우저에서 1,504px 스크롤한 뒤에도 우측 간격은 44.24px로 동일했고, 상단 위치는 둥실거림 애니메이션 범위 안에서만 20.64px에서 17.81px로 변했습니다.
