# 022 · 오늘의 운세 한복 캐릭터 플로팅 링크

## 목적

사주 페이지의 캡슐형 오늘의 운세 배너를 한복 캐릭터 이미지 자체로 바꾸고, 화면 우측 상단에서 오늘의 운세 화면으로 자연스럽게 안내합니다.

## 사용자 경험

1. 로그인한 사용자가 사주 페이지를 열면 한복을 입고 운세 구슬을 든 캐릭터가 우측 상단에 떠 있습니다.
2. 기존의 단순 SVG 캐릭터, 둥근 배너 배경과 설명 문구는 표시하지 않습니다.
3. 캐릭터 전체를 누르면 `/daily-fortune`으로 이동합니다.
4. 데스크톱과 모바일에서 캐릭터가 화면 밖으로 잘리지 않으며 기기의 상단·우측 안전 영역을 반영합니다.
5. 키보드 포커스와 스크린 리더용 링크 이름을 제공하고, 모션 감소 설정에서는 움직임을 멈춥니다.
6. 오늘의 운세 페이지에는 플로팅 캐릭터를 중복 표시하지 않습니다.

## 이미지 자산

- 사용자 제공 투명 PNG `public/saju-fortune-character-hanbok-v01.png`를 사용합니다.
- 이미지 비율을 유지하며 Next.js 이미지 최적화를 적용합니다.
- 장식 이미지는 대체 텍스트를 비우고 링크의 `aria-label`에서 목적을 설명합니다.

## 확인 기준

- 플로팅 링크가 우측 상단에 고정되고 하단 위치 규칙을 사용하지 않습니다.
- 캡슐형 배경과 기존 SVG·문구가 제거됩니다.
- 링크의 이동 경로와 접근성 이름이 유지됩니다.
- 모바일 안전 여백, 키보드 포커스, 모션 감소 설정이 동작합니다.
- 관련 자동 시험, 타입 검사와 프로덕션 빌드가 통과합니다.

## 검증 기록

- 2026-09-28: 기존 캡슐형 배너와 SVG 캐릭터·문구를 제거하고 사용자 제공 한복 캐릭터 PNG를 Next.js `Image`로 렌더링했습니다. 링크는 우측 상단 안전 영역에 고정하고 모바일 너비, 키보드 포커스, 움직임과 모션 감소 설정을 유지했습니다.
- 구현을 맡지 않은 독립 담당이 사주 페이지 전용 표시, PNG 실파일과 Next Image 렌더링, 링크 경로·접근성 이름·빈 대체 텍스트, 기존 SVG·문구 제거, 우측 상단·모바일 안전 영역, 키보드 포커스와 모션 감소 시험을 보강했습니다.
- `npm run check`에서 TypeScript 검사와 전체 자동 시험 134개가 통과했고, `npm run build`에서 프로덕션 빌드가 성공했습니다.
- 로컬 사주 화면에서 링크의 접근성 이름과 180×208px 우측 상단 고정 영역, 이미지 로딩 완료 상태를 확인했습니다.
