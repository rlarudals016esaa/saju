# 023 · 저장 사주 기반 간단 오늘의 운세

## 목적

별도 AI 호출이나 예약 작업 없이, 로그인 사용자의 최신 저장 사주 계산값과 한국 기준 오늘 날짜만으로 오늘의 운세를 즉시 보여줍니다.

## 사용자 경험

1. 사용자가 사주 페이지의 한복 캐릭터를 누르면 오늘의 운세 화면으로 이동합니다.
2. 화면을 열 때 계정에 저장된 최신 사주 1건을 조회합니다.
3. 최신 사주의 일간 오행·오행 분포와 오늘 날짜의 간지를 조합해 종합운·일/학업운·금전운·관계운·오늘의 행동을 즉시 계산합니다.
4. 같은 저장 사주와 같은 한국 날짜에는 항상 같은 결과를 표시합니다.
5. 저장된 사주가 없으면 먼저 사주 해석을 만들도록 안내합니다.
6. 생년월일·출생시간 원문은 새로 저장하거나 복원하지 않습니다.
7. 운세는 자기 성찰용 참고 문구이며 미래 사건, 합격, 수익 등을 확정하지 않습니다.

## 기술 범위

- 기존 `lib/saju` 계산으로 한국 날짜의 일진을 결정합니다.
- Gemini API, `SUPABASE_SERVICE_ROLE_KEY`, `CRON_SECRET`, Vercel Cron을 사용하지 않습니다.
- 별도 오늘의 운세 테이블이나 최근 30일 이력을 만들지 않습니다.
- 로그인 사용자의 기존 `saju_readings` 행을 현재 RLS 범위 안에서 읽습니다.
- 오늘의 운세 API는 GET만 제공하며 저장이나 외부 서비스 호출을 하지 않습니다.

## 확인 기준

- 최신 저장 사주가 있으면 오늘 날짜와 간단 운세가 즉시 반환됩니다.
- 다른 날짜 또는 다른 일간·오행 분포에는 계산 근거에 맞는 결과가 나옵니다.
- 비로그인 요청은 사주 조회 전에 거절됩니다.
- 저장 사주 없음과 조회 실패를 구분해 안내합니다.
- 코드와 설정에 오늘의 운세용 Cron·관리자 키·Gemini 의존성이 남지 않습니다.
- 관련 자동 시험, 타입 검사와 프로덕션 빌드가 통과합니다.

## 검증 기록

- 2026-09-28: 최신 `saju_readings` 한 건의 일간·오행 분포와 한국 기준 오늘 간지를 조합하는 결정적 계산을 구현했습니다. 오늘의 운세용 Gemini 호출, 관리자 클라이언트, Cron 경로·설정, 별도 운세 테이블 마이그레이션과 최근 30일 이력을 제거했습니다.
- 구현을 맡지 않은 독립 담당이 결정적 계산, 한국 날짜 경계, 입력별 결과 차이, 손상 데이터 거절, 비로그인 선차단, 최신 사주 조회, 사주 없음·조회 실패, 화면의 즉시 GET과 재시도를 검증했습니다.
- `npm run check`에서 TypeScript 검사와 전체 자동 시험 127개가 통과했고, `npm run build`에서 프로덕션 빌드가 성공했습니다.
- 로그인된 로컬 화면에서 `2026-09-28 · 을사일` 기준으로 종합운·일/학업운·금전운·관계운·오늘의 행동이 즉시 표시되는 것을 확인했습니다.
