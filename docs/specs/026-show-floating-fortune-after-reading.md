# 026 · 사주 해석 결과 이후 플로팅 배너 표시

## 목적

생년월일 입력 중에는 플로팅 배너를 숨기고, `내 사주 알아보기` 요청이 성공해 해석 결과가 보일 때 오늘의 운세 플로팅 캐릭터 링크를 표시합니다.

## 범위

- `/reading`에서 해석 결과가 없을 때는 플로팅 링크를 표시하지 않습니다.
- 해석 결과가 성공적으로 생성되면 같은 페이지에 링크를 표시합니다.
- 요청 중이거나 실패한 경우 결과가 없는 상태라면 링크를 표시하지 않습니다. 이전 결과가 화면에 남아 있으면 그 결과와 함께 링크도 유지합니다.
- 결과를 닫거나 삭제하면 링크도 숨깁니다.
- 오늘의 운세 페이지와 다른 화면의 기능은 변경하지 않습니다.

## 확인 기준

- 입력 전에는 배너가 없고 성공 결과가 나온 뒤에는 배너가 있습니다.
- 결과 닫기·삭제 후에는 배너가 없습니다.
- 관련 자동 시험, 전체 검사와 빌드가 통과합니다.

## 검증 기록

- 독립 작성 관련 시험 7개 통과: 초기 입력·성공 결과·결과 닫기/삭제·재요청 오류 시 이전 결과 유지·접근성 확인.
- 전체 자동 시험 130개와 TypeScript 검사 통과.
- 배포용 빌드 통과.
- 실제 사용자 계정의 Gemini 해석 생성과 화면 동작은 아직 직접 확인하지 않음.
- 참가자 확인: 아직 없음.
