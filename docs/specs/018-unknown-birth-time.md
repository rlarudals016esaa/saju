# 018 · 출생시간 미상 입력

## 목적

정확한 출생시간을 모르는 사용자도 임의의 시주를 실제 정보처럼 사용하지 않고 사주 해석을 요청할 수 있게 합니다.

## 이번 단계의 동작

1. 출생시간 입력 옆에 `시간 모름` 선택 항목을 둡니다.
2. `시간 모름`을 선택하면 시간 입력을 비활성화하고, 서버에는 출생시간 미상 여부를 명시적으로 전달합니다.
3. 서버는 출생시간 미상 입력을 다시 검증합니다. 연주·월주·일주 계산을 위해 정오를 기준 시각으로 사용하지만 시주는 결과에서 제외하며, 오행 분포도 세 기둥의 천간·지지 6자만 집계합니다.
4. 계산 결과에 출생시간 반영 여부를 저장하고 Gemini에도 시주가 제외된 자료임을 알려, 없는 시주나 정확한 출생시간을 추측하지 못하게 합니다.
5. 새 결과와 저장 이력에 `출생시간 미반영`을 표시합니다. 정확한 출생시간이 없어 시주가 제외되고, 절기 전환일이나 23시 전후 출생처럼 시간에 따라 기둥이 달라지는 경우 결과가 덜 정확하거나 아쉬울 수 있음을 안내합니다.
6. 기존 네 기둥 저장 결과는 출생시간이 반영된 결과로 계속 읽고 표시합니다.

## 제외할 것

- 임의의 시주를 생성하거나 사용자가 모르는 시간을 추측하지 않습니다.
- 출생시간 범위를 받아 가능한 여러 사주를 비교하지 않습니다.
- 시간 미상 결과를 정확한 네 기둥 결과와 동일한 정밀도라고 안내하지 않습니다.

## 확인 기준

- 시간을 입력한 기존 흐름은 네 기둥과 오행 8자를 그대로 계산합니다.
- `시간 모름`을 선택하면 빈 시간으로 제출할 수 있고, 세 기둥과 오행 6자만 결과·Gemini 입력·저장 데이터에 포함됩니다.
- 시간을 입력하지 않고 `시간 모름`도 선택하지 않으면 구체적인 입력 오류를 표시합니다.
- 새 결과와 저장 이력 모두 미반영 안내와 정확도 한계를 표시합니다.
- 기존 저장 데이터와 관련 기능이 계속 정상 동작합니다.
