# 014 · 운의 흐름 배너 밤하늘 배경

## 목적

사용자가 지정한 밤하늘 이미지를 결과 화면의 `운의 흐름 살펴보기` 배너 배경에 적용합니다.

## 범위

- 첨부한 밤하늘 이미지를 앱의 정적 이미지로 추가하고, 운의 흐름 배너에만 사용합니다.
- 기존 페이지 전체 배경과 연간 흐름 계산·문구는 변경하지 않습니다.
- 이미지 위에 어두운 반투명 막을 얹어 흰 글씨를 읽기 쉽게 하고, 현재 연도의 흰 카드와 다른 연도 카드의 대비를 유지합니다.
- 좁은 화면에서도 배너와 연도 카드가 잘리지 않아야 합니다.

## 확인 기준

- 배너 배경에 지정한 밤하늘 이미지가 보이고 기존 파란 그라데이션이 사라집니다.
- 페이지 배경과 현재 연도 카드 스타일은 그대로입니다.
- 자동 시험, 타입 검사, 빌드가 통과하며 브라우저에서 이미지 로드와 글씨 가독성을 확인합니다.

## 검증 기록

- 첨부 PNG를 그대로 복사했으며 SHA-256 `7AACEF7680C0E966C29768C3C524DCEF0761D5B4EE149C2506A2D9DDED630100`, 크기 1672×941을 독립 시험으로 확인했습니다.
- 독립 담당이 이미지 무결성, 배너 전용 배경, 글씨·연도 카드 대비 시험 3개를 작성·실행했습니다.
- 최종 `npm run check`: TypeScript 검사와 자동 시험 83개 통과. `npm run build`: 성공.
- 로컬 브라우저의 저장된 결과 화면에서 배너 배경이 새 이미지 URL을 참조하고, 페이지 배경은 기존 이미지 URL을 유지하며, 배너 글씨는 흰색인 것을 확인했습니다. 이미지 요청은 HTTP 200으로 응답했습니다.
- 배너의 새 이미지와 카드가 실제 화면에 표시되는 것을 확인했습니다. 참가자의 육안 확인은 아직 없습니다.
