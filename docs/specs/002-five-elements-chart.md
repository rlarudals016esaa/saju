# 002 · 오행 오각형 그래프

## 목적

사용자가 목·화·토·금·수의 개수를 오각형에서 비교하고, 어느 항목이 상대적으로 적거나 많은지 읽을 수 있게 합니다.

## 동작

1. 기존 `SajuChart.elements`의 목·화·토·금·수 개수를 사용합니다. 계산 방식은 바꾸지 않습니다.
2. 결과의 성향 요약 다음에 다섯 꼭짓점을 가진 그래프를 표시합니다. 꼭짓점은 목 → 화 → 토 → 금 → 수 순서이며, 각 값과 실제 개수를 함께 보여줍니다.
3. 개수 0~1은 '적은 편', 2는 '보통', 3 이상은 '많은 편'으로 표시합니다. 이 구분은 여덟 글자의 단순 개수를 읽기 위한 화면 기준입니다.
4. 그래프 아래에 다섯 항목의 개수와 구분을 글로 다시 보여줍니다. 색이나 모양만으로 정보를 전달하지 않습니다.
5. 천간과 지지의 대표 오행 8자를 센 값임을 설명합니다. 오행의 강약, 성격, 운명을 확정하는 지표로 쓰지 않습니다.
6. 화면 폭이 좁아도 그래프와 글이 잘리지 않게 합니다.

## 범위

- 오각형은 기존 웹 화면에서 SVG로 그립니다. 이미지 파일이나 새 외부 서비스는 필요하지 않습니다.
- 조언 문구를 만드는 방식과 LLM API 연결은 변경하지 않습니다.

## 확인 기준

- 다섯 값의 합계가 8이고, 화면의 숫자와 그래프 값이 일치합니다.
- 값이 0인 꼭짓점은 중심에 오며, 가장 큰 값은 다른 작은 값보다 멀리 표시됩니다.
- 구분 기준과 계산의 한계가 화면에 보입니다.
- 기존 성향 요약과 네 분야 조언이 계속 동작합니다.

## 검증 기록

- `npm run check`: 형식 검사와 자동 시험 22개 모두 통과. 별도 검증 담당이 실제 사주 사례를 이용해 0·1·2·3·4·5개 경계와 합계 8을 확인함.
- `npm run build`: 배포용 빌드 성공.
- 브라우저: `2000-01-01 12:00` 결과가 목 1·화 3·토 3·금 0·수 1로 표시되고, 많은 편은 화·토, 적은 편은 목·금·수로 보임.
- 화면: 일반 화면과 폭 390px 화면에서 그래프, 꼭짓점 글씨와 숫자 카드가 잘리지 않는 것을 확인함.
