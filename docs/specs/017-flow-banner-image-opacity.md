# 017 · 운의 흐름 배너 이미지 투명도

## 목적

`운의 흐름 살펴보기` 배너의 밤하늘 이미지를 50% 투명하게 표시합니다.

## 범위

- 밤하늘 이미지 위에 배너의 남색 배경을 알파값 0.5로 겹칩니다. 이미지와 배경색이 절반씩 섞이는 효과입니다.
- 배너의 글씨와 연도 카드는 투명하게 만들지 않습니다.
- 페이지 전체 배경 이미지와 다른 결과 영역은 변경하지 않습니다.

## 확인 기준

- 배너의 이미지가 50% 투명하게 보이고 글씨·카드의 대비가 유지됩니다.
- 새 결과와 저장된 결과에 같은 배너가 적용됩니다.
- 자동 시험과 빌드가 통과합니다.

## 검증 기록

- 독립 담당이 배경의 정확한 알파값 0.5와 글씨·카드에 요소 전체 투명도가 적용되지 않은 것을 검사하는 시험을 보강했습니다. 관련 시험 4개가 통과했습니다.
- 최종 `npm run check`: TypeScript 검사와 자동 시험 87개 통과. `npm run build`: 성공.
- 저장된 결과 화면에서 배너 배경의 계산된 스타일이 50% 남색 오버레이와 지정 이미지로 구성되고, 배너·현재 연도 카드의 요소 투명도가 1이며 흰 글씨가 유지되는 것을 확인했습니다. 페이지 전체 배경은 기존 이미지를 유지합니다.
- 참가자의 육안 확인은 아직 없습니다.
