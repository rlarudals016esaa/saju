# 005 · 반투명 읽기 영역

## 목적

밤하늘 배경이 가운데 읽기 영역에서도 은은하게 보이도록 하면서 글의 가독성을 유지합니다.

## 동작

1. 입력과 결과를 감싸는 큰 박스를 흰색 알파값 0.2로 표시합니다. 최초 0.5에서 0.35를 거쳐 배경이 더 보이도록 2026-09-23에 조정했습니다.
2. 내부 결과 영역은 별도 흰 배경을 겹치지 않아 실제 투명도가 짙어지지 않게 합니다.
3. 배경을 흐리게 처리하고 기존 글자 대비와 입력란의 밝은 표면을 유지합니다.
4. 사주 입력, 분석, 오행 그래프, 흐름 배너와 관계 카드는 그대로 동작합니다.

## 확인 기준

- 큰 박스의 배경이 `rgba(255, 255, 255, 0.2)`입니다.
- 결과 영역이 큰 박스 위에 다시 불투명한 흰 바탕을 만들지 않습니다.
- 작은 화면과 데스크톱에서 글을 읽을 수 있습니다.
- 자동 시험과 배포용 빌드가 통과합니다.

## 검증 기록

- 별도 검증 담당이 바깥 박스의 흰색 50% 투명도와 안쪽 결과의 투명 배경을 확인하는 자동 시험을 추가하고 실행함.
- `npm run check`: 형식 검사와 자동 시험 28개 모두 통과함.
- `npm run build`: 배포용 빌드 성공.
- 브라우저의 넓은 화면과 폭 390px 화면에서 입력·결과 텍스트를 확인하고, 보조 글자색을 더 진하게 조정함.
- 2026-09-23: 사용자 요청으로 흰색 배경 알파값을 0.5에서 0.35로 낮춤. 최초 구현의 검증 기록은 위에 보존함.
- 새 기준의 독립 시험 3개와 전체 자동 시험 69개, TypeScript 검사·배포용 빌드가 통과함. 로그인된 이력 화면에서 실제 계산된 배경값 `rgba(255, 255, 255, 0.35)`와 글씨 가독성을 확인함.
- 2026-09-23: 35% 읽기 박스에서 `사주 계산값 자세히 보기` 접기·펼치기 글씨를 흰색으로 바꾸고 밤하늘 배경 위에서도 읽히도록 어두운 그림자를 적용함.
- 새 결과·이력 공통 스타일 시험 2개를 추가해 전체 71개 자동 시험과 TypeScript 검사·배포용 빌드를 통과함. 로그인된 이력 화면에서 실제 글자색 `rgb(255, 255, 255)`를 확인함.
- 2026-09-23: 사용자 요청으로 읽기 박스의 흰색 알파값을 0.35에서 0.2로 낮춤. 앞선 35% 검증 기록은 당시 결과로 보존함.
- 20% 기준으로 전체 자동 시험 78개, TypeScript 검사와 배포용 빌드가 통과함. 실제 화면의 20% 표시 여부는 참가자 확인 전임.
