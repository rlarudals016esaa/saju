# 001 · 성향 요약과 분야별 조언

## 목적

사주 계산값을 처음 보는 사람도 결과의 맨 앞에서 성향·강점·주의할 점을 이해하고, 관심 분야의 조언을 읽을 수 있게 합니다.

## 이번 단계의 동작

1. 기존 양력 생년월일·출생시간 입력과 사주 계산을 유지합니다.
2. 계산에 성공하면 일간의 오행(목·화·토·금·수)을 기준으로 준비된 성향 문구를 선택합니다. 같은 계산 결과는 같은 문구를 보여줍니다.
3. 결과 맨 앞에 핵심 성향 한 문장, 강점, 주의할 점을 배치합니다.
4. 취업·연애·인간관계·삶의 흐름 네 분야 중 하나를 고르면 해당 조언과 스스로 생각해볼 행동을 표시합니다. 첫 선택은 취업입니다.
5. 기존 일주·일간·사주 네 기둥은 상세 정보 영역에 남깁니다.
6. 안내 문구가 전통적 사주 해석을 바탕으로 한 자기 성찰용 참고이며 미래나 개인의 성격을 확정하지 않음을 표시합니다.
7. 입력 오류는 기존처럼 구체적으로 알려주고, 계산에 실패하면 잘못된 결과를 남기지 않습니다.

## 구조

- 사주 계산: `lib/saju/chart.ts` 유지.
- 해석 데이터와 선택: 별도 `lib/saju/reading.ts`의 순수 함수로 분리해, 나중에 LLM API를 연결할 때 결과 화면의 데이터 형식을 유지할 수 있게 합니다.
- 화면: `app/saju-form.tsx`에서 입력, 결과 요약, 분야 선택, 상세 계산값을 표시합니다.
- 외부 API 호출과 계정·저장·결제 기능은 이번 단계에 넣지 않습니다.

## 확인 기준

- 유효한 입력에서 요약과 네 분야를 확인할 수 있습니다.
- 분야를 바꿔도 사주 계산값과 요약은 유지되며 해당 조언만 바뀝니다.
- 5가지 일간 오행 모두 해석 데이터가 있고, 같은 입력은 같은 결과를 만듭니다.
- 빈 입력이나 유효하지 않은 날짜는 결과 대신 안내를 보여줍니다.
- 데스크톱과 좁은 화면에서 글과 선택 버튼이 잘리지 않습니다.

## 검증 기록

- `npm run check`: 형식 검사와 자동 시험 19개 모두 통과. 기존 사주 계산 시험 16개 포함.
- `npm run build`: 배포용 빌드 성공.
- 브라우저: 유효한 입력 `2005-12-23 08:37`에서 요약과 기본 분야 조언, 기존 신사일주가 표시됨. 연애 분야 선택 시 조언 내용이 바뀌는 것을 확인함.
- 화면: 일반 화면과 폭 390px의 휴대전화 화면에서 결과 카드와 글이 잘리지 않는 것을 확인함.
- 입력값 재확인: 새로 연 화면에서 제출 전후 `08:37`이 유지되는 것을 확인함.
- 2026-09-23: 사용자 요청으로 새 결과와 저장 이력의 요약 카드 제목을 `강점`·`살펴볼 점`으로 짧게 표시합니다. 카드 본문과 결과 데이터는 그대로 둡니다.
- 새 결과·이력의 제목과 본문 연결을 확인하는 독립 시험 2개를 추가했습니다. 전체 자동 시험 80개, TypeScript 검사와 배포용 빌드가 통과했고 저장 이력 화면에서 두 제목을 확인했습니다.
