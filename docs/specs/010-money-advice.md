# 010 · 분야별 금전 조언

## 목적

기존 네 분야에 `금전`을 추가해 돈을 다루는 습관을 자기 성찰의 관점에서 돌아볼 수 있게 합니다.

## 범위

- 새 Gemini 해석에는 취업·금전·연애·인간관계·삶의 흐름 다섯 분야가 모두 있어야 합니다. 금전 항목도 짧은 설명과 지금 해볼 일 하나를 제공합니다.
- 금전 내용은 소비 기록, 예산과 목표, 충동적 결정 전 점검처럼 사용자가 자신의 상황을 살펴볼 질문에 집중합니다. 사주로 재산·수익·복권 당첨 시기 등을 예측하거나 특정 투자상품 매매·대출을 권하지 않습니다.
- 기존 오행별 기본 문구에도 금전 항목을 추가합니다.
- 이미 저장된 네 분야 결과는 오류 없이 열 수 있어야 합니다. 빠진 금전 항목을 실제 AI 조언인 것처럼 만들지 않고, 해당 결과에는 금전 조언이 없다는 안내를 표시합니다. 새로 생성한 AI 응답에서 금전 항목이 빠지면 실패로 처리합니다.
- 데이터베이스 테이블 구조는 바꾸지 않습니다. 결과 JSON의 새 항목만 추가하고, 이전 형식을 읽을 때만 호환 처리합니다.

## 확인 기준

- 새 결과 화면과 이력 화면에 금전 분야가 나타납니다.
- Gemini 요청 형식은 금전 분야를 필수로 요구하고, 응답에서 빠지면 거절합니다.
- 금전 결과에 확정 수익·투자 권유 같은 문구가 나오지 않도록 프롬프트와 응답 검사를 보강합니다.
- 기존 네 분야 저장 결과가 여전히 열리며, 금전 항목에는 이전 결과임을 분명히 표시합니다.
- 자동 시험·형식 검사·빌드와 기존 계산 화면이 통과합니다.

## 검증 기록

- 2026-09-23: 조언 분야 순서에 금전을 추가하고, 오행별 기본 문구와 Gemini 필수 출력 형식·프롬프트·응답 검사를 확장했습니다. 새 결과에서 금전이 빠지면 실패하고, 기존 네 분야 결과는 금전이 없는 과거 결과임을 명시해 표시합니다. 데이터베이스 테이블은 변경하지 않았습니다.
- 독립 시험을 보강해 전체 자동 시험 60개, TypeScript 검사와 배포용 빌드가 통과했습니다. 코인 매수 권유, 대출 투자 권유, 확정 수익, 복권 당첨 시기 문구를 거부하는 시험을 포함합니다.
- 예시 사주 계산값으로 실제 `gemini-3.5-flash-lite` 호출을 한 번 수행해 다섯 분야와 금전 설명·행동이 생성됨을 확인했습니다. 기존 로그인 계정의 과거 네 분야 결과가 `/history`에서 열리고 금전 항목에 이전 결과 안내가 표시되는 것도 확인했습니다. 사용자의 실제 새 입력으로 화면을 확인하거나 새 저장 행을 만들지는 않았습니다.
