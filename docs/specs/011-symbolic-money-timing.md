# 011 · 금전 기회 시기 해석

## 목적

금전 조언에서 “돈이 들어오는 시기”를 궁금해하는 사용자를 위해, 사주 전통의 오행 관계를 바탕으로 연도 단위의 **상징적 금전 기회 시기**를 보여줍니다. 실제 소득·수익·성공 여부를 예측하거나 보장하는 기능은 아닙니다.

## 계산과 표시

1. 기존 사주 계산의 일간 오행을 기준으로, 일간이 극하는 오행을 재성(財星)의 대표 오행으로 둡니다. 전통 명리학의 해석 규칙을 소개하는 것이며 검증된 재무 예측 모델이라는 뜻은 아닙니다.
2. 한국 시간의 올해부터 향후 9년까지, 매년 입춘 이후 6월 15일의 연주 천간 오행을 기존 계산기로 구합니다. 재성 오행이 나오는 첫 해와 이어지는 해가 있으면 함께 표시합니다. 월·일 단위로 좁히거나 수입 금액·확률·등급을 만들지 않습니다.
3. 금전 탭에서 `지금 해볼 일`보다 앞에 “사주에서 금전 기회로 읽는 시기”라는 제목, 해당 연도, 계산 근거를 표시합니다. 올해 기준으로 다시 계산한 참고임을 적습니다.
4. “그 해에 돈이 반드시 들어온다”, “투자 성공”, “가난/부자 운명”처럼 확정하거나 공포를 주는 표현은 쓰지 않습니다. 실제 돈의 흐름은 소득·지출·환경·선택에 따라 달라질 수 있음을 안내합니다.
5. 이 시기는 저장된 AI 문장이 아니라 화면에서 계산한 값이므로 이전 결과를 열어도 현재 연도 기준으로 다시 표시합니다. 기존 결과 JSON과 DB 구조는 바꾸지 않습니다.

## 확인 기준

- 예시 사주에서 일간이 극하는 오행과 첫 해당 연도(및 연속 연도)가 결정적으로 계산됩니다.
- 금전 탭의 시기 설명이 행동 조언보다 앞에 있고, 이력 화면에서도 같은 기준으로 나타납니다.
- 다른 분야에는 금전 시기를 표시하지 않으며, 수익 금액·성공 보장 문구가 없습니다.
- 새·예전 결과 모두 열리고 기존 자동 시험·형식 검사·빌드가 통과합니다.

## 검증 기록

- 2026-09-23: 일간 오행과 연주 천간의 재성 관계로 현재 한국 연도부터 10년 안의 첫 해당 연도 및 연속 연도를 계산했습니다. 새 결과와 저장된 이력의 금전 항목에서 행동 조언 앞에 표시하며, 실제 수입 보장이 아니라는 안내를 덧붙였습니다. 결과 JSON과 DB 구조는 변경하지 않았습니다.
- 독립 시험 5개를 추가해 전체 자동 시험 65개, TypeScript 검사와 배포용 빌드가 통과했습니다. 로그인된 이력 화면에서 기존 결과의 금전 항목에 연도·근거·주의 문구가 표시되는 것을 확인했습니다. 사용자 본인의 새 입력으로 결과를 생성하지는 않았습니다.
