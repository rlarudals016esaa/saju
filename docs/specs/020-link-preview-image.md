# 020 · 링크 공유 미리보기 이미지

## 목적

카카오톡 등에서 서비스 또는 결과 공유 링크를 붙였을 때 밤하늘 미리보기 이미지를 표시합니다.

## 범위

- 현재 페이지 배경으로 쓰는 별·달·산 밤하늘 사진을 참고해 가로형 미리보기 이미지를 제작합니다.
- 사이트 공통 제목·설명과 공개 이미지 주소를 Open Graph 및 Twitter 카드 메타데이터로 제공합니다.
- 로그인 화면과 결과 공유 링크에서 같은 미리보기 이미지를 사용합니다. 개인별 생년월일이나 해석 문장은 이미지·메타데이터에 포함하지 않습니다.
- 현재 페이지 배경 사진과 운의 흐름 배너 사진은 변경하지 않습니다.

## 확인 기준

- 생성한 이미지가 앱 안에 저장되고 링크에서 공개적으로 읽힙니다.
- HTML에 절대 주소의 `og:image`와 `twitter:image`, 제목·설명이 표시됩니다.
- 자동 시험과 빌드가 통과합니다.
- 실제 카카오톡에서의 표시 여부는 공개 주소에 배포한 뒤 확인합니다. 로컬호스트 주소로는 외부 미리보기를 확인할 수 없습니다.

## 검증 기록

- 내장 이미지 생성 도구로 기존 페이지 배경 사진을 참고해 달·별·산을 유지하고 제목 `나를 이해하는 사주 이야기`를 넣은 1730×909 PNG를 제작해 `public/saju-link-preview-2026-09-23-v01.png`에 저장했습니다.
- 독립 담당이 이미지 크기·무결성, 공통 Open Graph/Twitter 설정, 개인정보 비포함, 공개 주소 선택 순서를 검증하는 시험 3개를 작성·실행했습니다.
- 최종 `npm run check`: TypeScript 검사와 자동 시험 107개 통과. `npm run build`: 성공.
- 로컬 HTTP 응답에서 `og:title`, 절대 주소 `og:image`, 이미지 크기, `twitter:card`, `twitter:image`를 확인했고 이미지 요청은 HTTP 200·`image/png`였습니다.
- 카카오톡의 실제 썸네일은 외부에서 접근 가능한 주소에 배포한 뒤 확인해야 합니다. 현재 로컬호스트만 검증했습니다.
