# 013 · 어두운 배경의 글자 대비

## 목적

밤하늘과 흰색 20% 반투명 읽기 박스 위에서 검은 글씨가 잘 보이지 않는 문제를 해결합니다.

## 동작

1. 반투명 읽기 박스의 기본 글자·보조 설명·제목·링크·그래프 글자를 밝은 색으로 표시합니다.
2. 실제로 밝은 배경을 가진 입력칸, 요약 카드, 금전 시기 카드, 행동 카드, 관계 카드, 이력 목록에는 어두운 글자를 유지합니다.
3. 운의 흐름 배너 및 올해 흰색 카드의 기존 대비를 유지합니다.
4. 배경 이미지는 변경하지 않습니다. 읽기 박스의 흰색 알파값은 별도 사용자 요청에 따라 0.2로 조정했습니다.

## 확인 기준

- 로그인·입력·이력·결과 화면의 반투명 박스에서 글씨가 밝게 보입니다.
- 밝은 카드 안의 글씨는 어둡게 보여 대비가 유지됩니다.
- 자동 시험과 빌드를 통과하고 실제 화면에서 확인합니다.

## 검증 기록

- 2026-09-23: 읽기 박스의 기본 글씨와 보조 글씨, 이동 링크, 오행 그래프 축 글씨를 밝게 바꿨습니다. 입력칸·요약·금전 시기·행동·관계·이력·올해 카드의 실제 밝은 배경에는 어두운 글씨를 유지했습니다. 배경의 알파값 0.35는 그대로입니다.
- 독립 시험 4개를 포함한 전체 자동 시험 78개, TypeScript 검사와 배포용 빌드가 통과했습니다. 로그인된 입력 화면에서 흰 글씨와 어두운 입력칸 글씨를 육안으로 확인했고, 저장 결과 화면에서 주요 카드의 계산된 글씨색을 확인했습니다.
