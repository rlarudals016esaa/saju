# 015 · 결과 영역 제목 크기 통일

## 목적

`나의 오행 분포`와 `분야별 조언` 제목을 `운의 흐름 살펴보기`와 같은 25px로 표시합니다.

## 범위

- 새 결과와 저장된 결과에 공통으로 적용되는 CSS만 변경합니다.
- 두 제목의 글자 크기만 변경하고 기존 글자 굵기, 요약 카드 제목, 본문 크기, 계산 결과는 유지합니다.
- 좁은 화면에서도 제목이 잘리지 않도록 확인합니다.

## 확인 기준

- 세 영역 제목의 계산된 글자 크기가 같습니다.
- 새 결과와 저장된 결과 모두 같은 제목 크기를 사용합니다.
- 자동 시험과 빌드가 통과합니다.

## 검증 기록

- 독립 담당이 세 영역 제목의 25px 일치, 요약 카드 제목의 18px 유지, 새 결과와 저장된 결과의 공통 스타일 사용을 검증하는 시험 2개를 추가했고 모두 통과했습니다.
- 최종 `npm run check`: TypeScript 검사와 자동 시험 85개 통과. `npm run build`: 성공.
- 로컬 브라우저의 저장 결과에서 세 제목의 계산된 크기가 모두 25px, 요약 카드 제목이 18px인 것을 확인했습니다. 폭 390px에서도 세 제목이 화면 안에 있고 가로로 넘치지 않았습니다.
- 참가자의 육안 확인은 아직 없습니다.
