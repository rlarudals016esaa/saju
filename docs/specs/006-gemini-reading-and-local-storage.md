# 006 · Gemini 사주 해석과 브라우저 결과 저장

## 목적

기존 사주 계산값을 바탕으로 개인별 성향·강점·주의할 점과 네 분야의 조언을 생성하고, 마지막 결과를 같은 브라우저에서 다시 볼 수 있게 합니다. 사주는 자기 성찰을 위한 참고이며 성격이나 미래를 확정하지 않습니다.

## 이번 단계의 범위

1. 사용자가 양력 생년월일과 출생시간을 제출하면 **서버**가 입력을 다시 검증하고 기존 `lib/saju/chart.ts`로 사주를 계산합니다. 브라우저에서 보내온 계산값을 신뢰하지 않습니다.
2. 서버가 계산된 사주 정보 중 해석에 필요한 값만 Gemini에 전달합니다. 생년월일·출생시간 원문, API 키, 다른 사용자의 정보는 프롬프트에 넣지 않습니다. 사주 계산 자체를 Gemini에게 맡기지 않습니다.
3. Google Gemini 모델 ID는 **`gemini-3.5-flash-lite`**로 고정합니다. 비밀 인증값인 API 키는 서버의 `GEMINI_API_KEY` 설정값에서만 읽고, 브라우저 코드·응답·Git에 포함하지 않습니다.
4. Gemini가 기존 `SajuReading` 형태로 한국어 해석을 생성합니다: 핵심 제목, 성향, 강점, 주의할 점, 취업·연애·인간관계·삶의 흐름 각각의 설명과 지금 해볼 일. 결과 형식을 지정해 요청하되, 서버에서 필수 항목·문자열 길이·빈 값·부적절한 단정 표현을 검사한 후에만 화면에 전달합니다.
5. 오행 수치와 오각형, 연도 흐름 배너, 일간 기준 관계 카드는 기존 계산 로직을 유지합니다. AI 문장과 계산 결과를 화면에서 구분할 수 있게 표시합니다.
6. 성공한 **가장 최근 결과 1건**의 표시용 계산값과 검증된 해석, 생성 시각, 데이터 형식 버전을 브라우저 `localStorage`에 저장합니다. 양력 생년월일·출생시간 원문과 API 키는 저장하지 않습니다. 새로고침 후 같은 브라우저에서 마지막 결과를 복원하고, 사용자가 저장 결과를 지울 수 있게 합니다. 다른 기기와 동기화하거나 여러 건의 이력을 관리하지 않습니다.
7. 생성 중에는 중복 제출을 막고 진행 상태를 표시합니다. 키 누락, 네트워크·한도 오류, 시간 초과, 응답 형식 오류는 구분 가능한 안내와 재시도 수단을 제공합니다. 실패한 새 결과를 저장하거나 기존 결과를 덮어쓰지 않습니다. 미리 작성한 문구를 AI가 만든 새 결과인 것처럼 조용히 대체하지 않습니다.

## 화면과 데이터 흐름

`입력 → 서버 검증·사주 계산 → Gemini 해석 요청 → 서버 응답 검증 → 결과 표시 → localStorage 저장`

- 서버 진입점: Next.js의 해석 요청 경로를 새로 만듭니다. 요청 크기와 입력 형식을 제한하고, 공개 배포 전에는 호출 남용을 막을 제한을 적용합니다.
- 출력 자료형: 기존 `SajuReading`과 화면 구성을 재사용합니다. 저장 자료에는 형식 버전을 두고, 오래되거나 손상된 자료는 무시하거나 삭제한 뒤 새 입력을 안내합니다.
- 개인정보 안내: 브라우저 저장은 계정 저장소가 아니며 같은 기기의 브라우저 사용자에게 보일 수 있음을 화면에 알립니다. 브라우저 저장 실패 시에도 생성된 결과는 현재 화면에 보여주되 저장되지 않았음을 알립니다.

## 제외할 것

- 로그인, 서버 데이터베이스, 여러 결과의 이력·기기 간 동기화, 결과 공유.
- Gemini를 통한 사주 계산, 미래 사건의 단정적 예측, 의료·법률·금전 결정의 확정적 조언.
- 결제, 유료 상담, 상세 궁합.

## 확인 기준

- 키가 설정된 환경에서 유효한 입력 1건이 `gemini-3.5-flash-lite`를 통해 완전한 네 분야 해석을 받고, 계산 수치는 기존 로직과 일치합니다.
- 브라우저의 네트워크 요청·응답과 빌드 파일에 API 키가 나타나지 않습니다.
- 새로고침하면 가장 최근 성공 결과 1건이 복원되고, 삭제하면 다시 나타나지 않습니다. 비어 있거나 손상된 저장 자료에서도 화면이 정상 작동합니다.
- 잘못된 입력, 키 누락, API 실패·시간 초과, 불완전한 AI 응답, 브라우저 저장 불가를 각각 시험합니다. 실패 시 가짜 새 결과를 보이지 않습니다.
- 키 없이 실행하는 자동 시험은 Gemini 응답을 모의 데이터로 대체해 형식 검사·화면 상태·저장을 검증합니다. 실제 API 연동은 사용자가 키를 설정한 뒤 별도로 확인합니다.
- 좁은 화면과 데스크톱에서 진행·오류·복원 상태와 긴 한국어 문장이 읽히며, 기존 사주 계산·오행·흐름·관계 기능도 통과합니다.

- Google 공식 모델 문서에서 모델 ID와 구조화된 출력 지원을 확인함: https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite
- API 키 관리: https://ai.google.dev/gemini-api/docs/api-key

## 검증 기록

- 서버에서 사주를 다시 계산하고, `gemini-3.5-flash-lite`에 계산 요약만 보내며, 구조화된 응답을 앱에서 재검증하도록 구현함. 브라우저에는 최근 결과 1건의 표시 자료만 저장하고 원본 출생일시와 키는 저장하지 않음.
- Google API의 새 `responseFormat` 형식은 실제 요청에서 HTTP 400으로 거절됨. 공식 문서의 `responseMimeType` + `responseSchema` 형식으로 조정한 뒤 실제 호출에 성공함. 응답 검증은 계속 서버에서 수행함.
- 별도 검증 담당이 해석 형식·확정 표현·모델 요청·오류·시간 초과·서버 입력·요청 제한·저장 복원 및 삭제를 포함한 자동 시험 14개를 추가함. 최종 `npm run check`에서 전체 41개가 통과함.
- `npm run build`: 페이지와 `/api/reading` 경로가 성공적으로 빌드됨.
- 현재 설정된 키 전체 문자열을 빌드된 브라우저용 `.next/static` 파일에서 검색한 결과 일치 파일 0개임. 키 자체는 출력하거나 문서에 기록하지 않음.
- 브라우저에서 예시 입력 `2000-01-01 12:00`으로 실제 Gemini 해석, 네 분야 조언, 기존 오행·흐름·관계 화면을 확인함. 새로고침 후 복원과 삭제 후 새로고침 시 결과가 없는 것도 확인함. 검증용 예시 결과는 삭제함.
- 공개 배포는 아직 하지 않음. 현재 요청 제한은 서버 인스턴스 메모리 방식이므로, 다중 인스턴스 공개 배포 전에는 공유 저장소 기반 제한과 운영 한도를 다시 검토해야 함.
