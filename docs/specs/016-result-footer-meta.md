# 016 · 결과 정보를 하단 서체 표기 앞으로 이동

## 목적

결과 상단의 제목과 해석·생성·저장 정보를 페이지 맨 아래 서체 표기 영역으로 이동합니다.

## 범위와 확인 기준

- 새 해석 결과와 저장 이력의 상세 결과가 보일 때만 하단 정보를 표시합니다.
- 생성 시각과 저장 상태는 고정 예시가 아닌 현재 결과 값을 사용합니다.
- 기존 상단의 중복 문구는 제거하고 결과 삭제 버튼과 서체 표기는 유지합니다.
- 로그인·입력 화면에는 결과 정보가 나오지 않습니다.
- TypeScript 검사, 자동 시험, 배포용 빌드가 통과합니다.

## 검증 기록

- 2026-09-23: 처음에는 상단을 유지하고 하단에 중복 표시했으나, 참가자의 뜻에 따라 상단 문구를 제거하고 공통 하단 서체 표기 앞으로 이동했습니다. `npm run check`에서 TypeScript 검사와 자동 시험 86개, `npm run build`가 통과했습니다. 화면 육안 확인은 아직 진행하지 않았습니다.
