# 025 · 생년월일 입력 페이지의 플로팅 링크 제거

## 목적

`/reading`의 생년월일 입력 화면에서 우측 상단 한복 캐릭터 플로팅 링크를 표시하지 않습니다.

## 범위

- `/reading`에서 플로팅 링크 렌더링만 제거합니다. 입력 폼, 해석 결과와 오늘의 운세 계산 기능은 유지합니다.
- `/daily-fortune` 직접 주소와 저장된 해석 화면의 `오늘의 운세` 이동 링크는 유지합니다.
- 캐릭터 이미지 파일이나 공통 스타일은 삭제하지 않습니다.

## 확인 기준

- `/reading`에서 플로팅 링크가 보이지 않으며 생년월일 입력과 사주 해석은 그대로 동작합니다.
- `/daily-fortune`과 저장된 해석 화면의 접근 경로는 그대로입니다.
- 관련 자동 시험, 타입 검사, 빌드가 통과합니다.

## 검증 기록

- 별도 작성한 관련 화면 시험 15개 통과.
- 전체 자동 시험 129개와 TypeScript 검사 통과.
- 배포용 빌드 통과.
- 로컬 `/reading` 화면에서 생년월일 입력 폼은 유지되고 플로팅 링크는 표시되지 않음을 확인.
- 참가자 확인: 아직 없음.
