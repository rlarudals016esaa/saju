# 012 · 하이원 원추리 제목체와 글자 굵기 계층

## 목적

서비스 전반에 하이원 원추리 제목체를 적용하고 배너·제목·본문을 글자 굵기로 구분합니다.

## 제약과 범위

- 강원랜드가 공공누리 제1유형(출처표시)으로 공개한 제목체 L·M·B를 사용합니다. 화면 하단에 저작권자와 공유마당 링크를 표시합니다.
- 눈누가 제공하는 웹폰트 주소를 사용해 L=300, M=500, B=700으로 연결합니다. 외부 웹폰트가 로드되지 않으면 시스템 글꼴을 대체로 사용합니다.
- 본문은 L, 영역 제목은 M, 페이지 및 배너 제목은 B를 사용합니다. 입력칸·버튼·오행 그래프 글자도 공통 서체를 상속합니다.
- 글꼴 변경이 결과 데이터와 사주 계산에 영향을 주지 않도록 합니다.

## 확인 기준

- 로그인·입력·이력 및 결과의 공통 텍스트가 같은 글꼴 설정을 상속합니다.
- 배너 제목, 각 영역 제목, 설명 문장 사이에 일관된 굵기 차이가 있습니다.
- 출처표시가 있고 굵기별 폰트 파일 로딩이 정상입니다.
- 자동 시험과 빌드를 통과하고 실제 화면의 가독성을 확인합니다.

## 검증 기록

- 2026-09-23: 눈누 웹폰트 L·M·B를 공통 CSS에 연결하고 로그인·입력·이력·결과 화면이 같은 글꼴을 상속하도록 했습니다. 페이지/배너 제목 700, 영역 제목 500, 본문 300으로 구분하고 입력칸·버튼·오행 그래프·상세 계산값도 같은 서체를 사용합니다. 화면 하단에 강원랜드와 공유마당 출처를 표시합니다.
- 독립 테스트 4개를 포함해 자동 시험 69개와 TypeScript 검사·배포용 빌드가 통과했습니다. 로그인된 저장 결과 화면에서 배너·본문의 계산된 굵기(700·300)와 영역 제목(500), 세 굵기의 웹폰트 로딩을 확인했습니다.
- 2026-09-23: 소개 문구의 최대 너비 520px 제한을 없애고 넓은 화면에서 한 줄로 표시했습니다. 760px 이하에서는 내용이 잘리지 않도록 자연스러운 줄바꿈을 유지합니다. 관련 독립 시험 3개를 포함한 전체 74개와 빌드가 통과했고, 입력 화면에서 실제 한 줄 표시를 확인했습니다.
