# 004 · 밤하늘 배경 적용

## 목적

참가자가 선택한 별과 초승달, 산 능선이 있는 밤하늘 이미지를 사주 서비스의 페이지 배경으로 사용합니다.

## 동작

1. 참가자가 첨부한 이미지를 변경하지 않고 프로젝트의 `public/`에 새 이름으로 보관합니다.
2. 페이지 전체에 이미지를 배경으로 표시합니다. 다양한 화면 크기에서 화면을 채우되 글을 읽을 수 있어야 합니다.
3. 제목은 밝은 색으로, 입력 영역과 결과 영역은 밝은 반투명 표면으로 표시해 대비를 확보합니다.
4. 기존 입력, 사주 계산, 오행 그래프, 흐름 배너와 관계 카드는 그대로 동작합니다.

## 확인 기준

- 브라우저에서 첨부 이미지의 별, 초승달과 산 능선이 배경으로 보입니다.
- 데스크톱과 폭 390px 화면에서 제목, 입력란과 결과 글을 읽을 수 있습니다.
- 원본 이미지와 프로젝트에 복사한 이미지의 SHA-256 값이 일치합니다.
- 기존 자동 시험과 배포용 빌드가 통과합니다.

## 검증 기록

- 참가자 첨부 PNG를 `public/saju-background-night-2026-09-23-v01.png`로 복사함. 원본과 복사본의 SHA-256이 일치하며, 이미지 크기는 1672×941px임.
- 별도 검증 담당이 PNG 내용·크기와 CSS의 실제 파일 참조를 자동 시험으로 확인함. 최종 `npm run check`에서 형식 검사와 자동 시험 27개 모두 통과함.
- `npm run build`: 배포용 빌드 성공.
- 브라우저에서 작은 화면과 1100px 화면의 별·초승달·산 능선, 제목·입력 영역·결과 카드의 가독성을 직접 확인함. 작은 화면에서 제목이 한 글자만 다음 줄로 넘어가지 않게 줄바꿈을 조정함.
