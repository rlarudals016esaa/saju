# 027 · 사주 해석 생일로 오늘의 운세 바로 보기

## 목적

사주 해석 결과에서 플로팅 배너를 누르면 생년월일을 다시 입력하지 않고 그 날짜를 바탕으로 오늘의 운세를 보여줍니다.

## 동작

1. 해석 입력 중에는 배너를 표시하지 않습니다. 해석 성공 시에만 현재 결과와 그 결과를 만든 양력 생년월일을 화면 메모리에 보유합니다.
2. 사용자가 배너를 누르면 해당 생일을 주소·브라우저 저장소·데이터베이스에 기록하지 않고 같은 탭의 다음 화면에 한 번 전달합니다.
3. `/daily-fortune`에서는 전달받은 생일로 기존 로그인 보호 API를 자동 호출하고 운세를 표시합니다. 날짜 입력 폼은 표시하지 않습니다.
4. 운세 계산에 실패하면 생일 재입력 대신 다시 시도 버튼을 제공합니다.
5. 새로고침·직접 주소 방문처럼 전달된 생일이 없으면 운세를 추측하지 않고 사주 입력 화면으로 돌아가는 안내를 보여줍니다.
6. 저장된 해석 이력은 출생일시 원문이 없으므로, 이력의 `오늘의 운세` 링크로 직접 들어온 경우에도 같은 안내를 보여줍니다.

## 확인 기준

- 해석 성공 뒤 배너 한 번 클릭으로 운세 계산을 시작하며 날짜를 다시 입력하지 않습니다.
- 해석 실패·결과 닫기·삭제 뒤에는 배너가 없고 생일을 전달하지 않습니다.
- 날짜가 없는 직접 접근에서 운세 API를 호출하지 않습니다.
- 생일이 URL, localStorage, sessionStorage, 데이터베이스에 저장되지 않습니다.
- 관련 시험, 전체 검사와 배포용 빌드가 통과합니다.

- 참가자 확인: 아직 없음.
