# 003 · 운의 흐름 배너와 관계 유형

## 목적

결과를 본 사용자가 지난 해·올해·내년의 연간 오행 흐름을 살펴보고, 맨 아래에서 전통적인 오행 관계상 도움과 조율의 주제를 읽을 수 있게 합니다.

## 동작

1. 결과 요약 다음에 연도별 흐름 배너를 보여줍니다. 한국 시간 기준 현재 연도의 전년·올해·다음 해를 표시합니다.
2. 각 연도의 대표 연주는 그해 입춘 이후인 6월 15일 정오의 기존 사주 계산 결과를 사용합니다. 일간 오행과 연주의 천간 오행 관계를 다섯 유형으로 분류해 짧은 성찰 문구를 보여줍니다.
3. 결과 맨 아래에 '잘 맞을 수 있는 사주 유형'과 '갈등이 생기기 쉬운 사주 유형' 카드를 보여줍니다. 사용자 일간을 기준으로 상생 관계의 오행과 상극 관계의 오행, 해당 천간의 예를 표시합니다.
4. 다른 사람의 사주 정보를 입력받거나 궁합 점수·미래 사건을 단정하지 않습니다. 이 표시는 일간 오행 하나만 사용한 간단한 참고임을 화면에 적습니다.
5. 기존 성향 요약, 오행 그래프, 분야별 조언, 상세 계산값을 유지합니다. LLM API는 연결하지 않습니다.

## 확인 기준

- 예시 입력에서 전년·올해·다음 해의 연도와 서로 다른 연주가 화면에 보입니다.
- 현재 연도는 시각적으로 강조됩니다.
- 목·화·토·금·수 각각에서 상생·상극에 해당하는 오행과 천간 예시가 정확히 매핑됩니다.
- 두 관계 카드가 결과의 마지막에 있고, 좁은 화면에서 잘리지 않습니다.
- 자동 시험과 기존 기능 시험이 통과합니다.

## 검증 기록

- 별도 검증 담당이 고정된 한국 시각으로 2025·2026·2027 연주, 다섯 오행의 연간 관계 주제, 상생·상극 오행과 천간 예시를 시험함.
- 최종 `npm run check`: 형식 검사와 자동 시험 25개 모두 통과.
- `npm run build`: 배포용 빌드 성공.
- 브라우저에서 `2000-01-01 12:00` 입력 시 2025 을사·2026 병오·2027 정미가 보이고, 토 일간의 관계 카드에 화 일간(병·정), 목 일간(갑·을)이 표시됨.
- 일반 너비에서 배너 3개 카드와 하단 관계 2개 카드가 나란히 보임. 좁은 화면에서는 세로로 바뀌며 내용이 잘리지 않음.
